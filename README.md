# ExitAnt USA DCA (분할 매수) — 키움증권

키움증권 계좌로 미국 ETF **TQQQ · SOXL** 을 현물로 분할 매수하는 자동매매 봇을 **내 Render 계정**에
백그라운드 워커로 띄웁니다. 봇은 미리 빌드한 Docker 이미지로 돌고, 이 저장소에는 **Render Blueprint(`render.yaml`)만**
있습니다 — 소스 코드는 없습니다.

## Render 에 배포

[![Deploy to Render](https://render.com/images/deploy-to-render-button.svg)](https://render.com/deploy?repo=https://github.com/ExitAnt-dev/infinite-kiwoom)

```
https://render.com/deploy?repo=https://github.com/ExitAnt-dev/infinite-kiwoom
```

1. 버튼(또는 링크)을 누르고 Render 에 로그인합니다.
2. Render 가 `render.yaml` 을 읽어 **백그라운드 워커 하나**를 제안합니다.
3. 아래 환경변수 4개를 입력합니다. `sync: false` 라 배포 화면에서 묻고 **내 Render 계정에만** 저장됩니다.
4. **Apply** 를 누르고 첫 배포가 끝날 때까지 기다립니다.
5. 텔레그램에서 봇에게 **`/start`** 를 보냅니다. 약관에 동의하면 **「🧪 모의 투자 모드로 진행할까요?」** 를 묻습니다 — 아래 「모의 투자」 참고.
   이어서 봇이 **이 서버의 IP** 를 알려 줍니다 — 아래 「IP 등록」대로 키움에 넣고
   **「✅ 등록했습니다」** 를 누르면 키움 연결을 확인한 뒤 설정으로 넘어갑니다.

## 배포 전에 준비할 것

- **해외주식(미국) 거래가 되는 키움증권 계좌.**
- **키움 REST API 앱키 · 시크릿키(실전투자).** [키움 REST API](https://openapi.kiwoom.com) 에서 API 사용 신청을 한 뒤
  「계좌 App Key 관리」에서 발급합니다. 키움 앱키는 계좌 하나에 묶여 있어 **계좌번호는 따로 넣지 않습니다.**
- **달러(USD) 예수금** — 또는 키움 **원화주문 서비스** 신청(원화로 미국 주식을 주문). 둘 다 없으면 매수가 건너뛰어지고 봇이 안내합니다.

## IP 등록 (꼭 필요)

키움은 앱키에 **등록한 IP 에서만** 주문 · 조회를 받습니다(「계좌 App Key 관리 → IP 등록」, 최대 10개).

1. Render 에서 이 서비스를 열고 오른쪽 위 **Connect → Outbound** 탭의 IP 를 확인해 키움 「IP 등록」에 넣습니다.
   여기 적힌 IP 는 같은 지역의 서비스가 함께 쓰는 주소라, 전부 넣어 두면 재배포로 서버가 바뀌어도 이어집니다.
2. 목록이 범위(예: `/28`)로만 나오거나 10개를 넘으면, 봇이 알려 주는 **이 서버의 지금 IP** 를 넣습니다.
3. 봇은 처음 설정 · 🟢 시작 · **재시작 뒤** 때마다 그때의 IP 를 보여 주고 「✅ 등록했습니다」를 기다립니다 — 누르기 전에는 매매를
   시작 · 재개하지 않습니다. 서버가 다시 시작되면 이전 전략을 그대로 이어 가겠다고 알리고 이 확인 하나만 받습니다. 연결이 안 되면 까닭(앱키 · IP)과 새 안내를 보냅니다.

## 환경변수

| 변수 | 넣을 값 |
|---|---|
| `KIWOOM_APP_KEY` | 키움 REST API 앱키(실전투자) |
| `KIWOOM_SECRET_KEY` | 키움 REST API 시크릿키 |
| `TELEGRAM_BOT_TOKEN` | [@BotFather](https://t.me/BotFather) 가 발급한 봇 토큰 |
| `TELEGRAM_CHAT_ID` | 내 텔레그램 채팅 ID — 봇은 다른 사람의 메시지에 답하지 않습니다 |

## 모의 투자

약관 동의 뒤 **「🧪 예 — 모의 투자」** 를 고르면 봇의 모든 주문 · 조회가 **키움 모의투자 서버**(`mockapi.kiwoom.com`)로만 나갑니다 — 실제 돈은
움직이지 않습니다. **「💼 아니오 — 실전 투자」** 면 실제 계좌로 매매합니다. 고른 모드는 고정 백업에 함께 저장돼 재시작 뒤에도 이어집니다.

- 모의투자는 [키움 REST API](https://openapi.kiwoom.com) 에서 **모의투자용 앱키**를 따로 발급받아야 합니다(실전 앱키는 모의 서버가 받지 않습니다).
  모의투자 앱키에도 위 「IP 등록」을 해 두세요.
- **모의투자만 쓸 때:** 위 표의 `KIWOOM_APP_KEY` · `KIWOOM_SECRET_KEY` 에 모의투자용 키를 넣고 「예」를 고르면 됩니다.
- **실전 · 모의를 둘 다 둘 때:** 위 칸에는 실전 키를 두고, Render 서비스 → **Environment** 에 아래 둘을 더해 저장합니다(저장하면 다시 시작합니다).
  넣지 않은 칸은 위 칸의 값을 모의투자에도 씁니다.

| 변수(선택) | 넣을 값 |
|---|---|
| `KIWOOM_MOCK_APP_KEY` | 모의투자용 앱키 |
| `KIWOOM_MOCK_SECRET_KEY` | 모의투자용 시크릿키 |

- 모드를 바꾸려면 메인 메뉴 → **처음부터 다시 설정** → 약관 동의 → 모드를 다시 고릅니다. 운용 중인 장부가 있으면 먼저 묻고, 바꾸면 봇이 건
  익절 주문만 취소하고 이전 계좌의 보유 주식은 그대로 둔 채 손을 뗍니다.
- 키움 모의투자가 미국주식의 어떤 기능을 받지 않으면 봇이 그 까닭(8104)을 알려 줍니다.

## 봇이 하는 일

- 매 미국 거래일 정규장 마감 직전(15:54 ET)에 정한 금액을 **나눠서 시장가로 삽니다**(하락한 날에 더, 오른 날에 덜).
- 산 묶음마다 **익절 지정가**를 겁니다. 지정가는 당일 만료라 다음 거래일 장 시작 직후(09:31 ET)에 같은 가격으로 다시 겁니다.
- 마감 뒤(16:05 ET) 정산합니다 — 체결 확인, 자산이 정한 비율만큼 늘면 일부를 금고에 보관, 정한 비율만큼 줄면 금고에서 다시 투입.
- 미국 주식은 **1주 단위**로만 삽니다. 운용 금액 × 매수 비율이 1주 가격보다 작으면 그날 매수를 건너뜁니다.
- 매수 여력(USD)이 그날 나갈 수 있는 가장 큰 매수분보다 적으면 그날은 매수하지 않고 알립니다(OKX · Gate 봇과 같은 규칙).
- 조기 마감일(13:00 ET)에는 그 마감에 맞춰 매수 · 정산 시각을 함께 당깁니다.
- 설정은 전부 텔레그램에서 합니다(한국어). TanQuant 백테스트 세팅을 붙여 넣어 한 번에 넣을 수도 있습니다.

## 동작 방식

- **미리 빌드한 이미지.** 워커는 Docker Hub 의 `docker.io/exitant/exitant-kiwoom-infinite:latest` 를 받습니다. 이미지에는
  컴파일된 실행 파일만 있고 파이썬 소스는 없습니다.
- **키는 내 것.** 키는 내 Render 환경변수에만 들어가고 키움 외에는 어디로도 보내지 않습니다.
- **디스크 불필요.** 설정과 장부는 봇이 텔레그램에 **고정해 두는 백업 메시지**로 재시작 뒤 되살립니다 — 그 고정 메시지를 지우지 마세요.

## 주의

- **인스턴스는 1개로 둡니다.** 2개 이상이면 텔레그램 `getUpdates` 충돌로 봇이 답하지 않습니다(`numInstances: 1`).
- Render **백그라운드 워커에는 무료 요금제가 없습니다** — Starter 이상을 고르세요.
- **「아니오 — 실전 투자」를 고르면 첫 시작부터 실거래입니다.** 처음이면 모의 투자로 한 바퀴 돌려 보거나, 작은 금액으로 시작해 매수 → 익절 한 바퀴를
  계좌에서 확인한 뒤 늘리세요.
- TQQQ · SOXL 은 **3배 레버리지 ETF** 라 값이 크게 움직입니다. 투자 판단과 손실의 책임은 이용자에게 있습니다.
